# Vibe Coding Toolkit · Caderno de estudo

[README](../README.md) · [Projeto original](https://github.com/soumatheusgomes/vibe-coding-toolkit) · [Licença](../LICENSE)

O material original reúne práticas, ferramentas e prompts para desenvolvimento assistido por IA. Esta cópia permite estudar o fluxo, comparar sugestões com um projeto próprio e adaptar uma técnica por vez, mantendo os créditos ao autor.

## Uma sessão de estudo

1. Leia o panorama em `docs/00-overview.md`.
2. Escolha uma tarefa pequena em um projeto de teste e descreva o resultado esperado.
3. Compare seu processo com `docs/02-playbook-onboarding.md`.
4. Use um único template ou prompt, confira o diff e execute as verificações do seu projeto.
5. Registre o que ajudou, o que falhou e quais adaptações você fez.

Os templates são exemplos para copiar e adaptar; não são executados automaticamente por este repositório. Confira as permissões e a finalidade de um comando antes de instalá-lo no seu ambiente. As experiências de produção descritas no material pertencem ao autor original.
